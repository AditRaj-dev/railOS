# RailOS Agent Instructions

Read and follow the existing RailOS implementation guidance in
`AGENTS.md — Codex RailOS Implementation & Integration Agent.md`.

For every frontend, product-design, accessibility, UX review, or design-system
task, begin with `.designpowers/skills/using-designpowers/SKILL.md` and route
through the applicable Designpowers workflow. Designpowers is project-local;
its skills live in `.designpowers/skills/` and its agent briefs live in
`.designpowers/agents/`.

The primary frontend is `apps/control-center`.
